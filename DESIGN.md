# ABDSHOP · «Вестник Бездны» – дизайн-система главной страницы

Версия 1.0 · десктоп 1280–1920 px · один файл `index.html`, чистый CSS без фреймворков.
Источник истины для кода: все цвета, шрифты, размеры, отступы и тайминги в `index.html` берутся только из переменных, перечисленных ниже. Сырые значения допустимы только внутри `:root`.

---

## 1. Философия и тон

**Концепция.** Главная страница – первая полоса газеты лаборатории. Товары – объявления рубрики каталога, архив – хроника изъятых коллекций, манифест – передовая, кнопки и статусы – штампы. Требование клиента: газета с красными и синими штампами в стиле трэш-польки.

**Баланс 70 / 30.** 70% – строгая газетная сетка, читаемый текст, чистые карточки. 30% – контролируемый хаос: штампы, наклоны, скотч, растр, рукописные пометки. У каждого элемента хаоса есть причина: он отмечает статус, цену или действие.

**Одно смелое место.** Смелость тратим на шапку и hero (пришлёпывание штампов, неточная привязка, гигантский заголовок). Остальные блоки спокойнее и работают на чтение и покупку.

**Тон текста.** Сухо, точно, чуть темно. Словарь лаборатории: образец, диагноз, калибровка, реестр, фонд, диссекция. Без восклицательных знаков, без маркетинговых оборотов, без канцелярита. Тире только короткое «–».

**Слова-ориентиры.** Ризограф, досье, старая медицинская карта, штамп «вещдок», фотокопия с потерянным контрастом.

## 6. Текстуры и эффекты (`--fx-*`)

| Токен | Значение | Применение |
|---|---|---|
| `--fx-grain` | SVG-шум `feTurbulence` 0.8, 3 октавы (data-URI) | один фиксированный слой `body::before` |
| `--fx-grain-opacity` | .5 | `mix-blend-mode: multiply`, `pointer-events: none` |
| `--fx-vignette` | радиальный градиент к `--color-vignette` | `body::after`, до 22% |
| `--fx-halftone-step` | 7px | растр только для фото бренда (лукбук, архив) |
| `--fx-misreg` | 3px | смещённая копия заголовка (hero синим, шапка – синим 2 px) |
| `--fx-fold` | linear-gradient с прозрачностью 5% | сгибы поверх статей hero |
| `--fx-stamp-filter` | `url(#rough-stamp)` 0.04 / scale 3.5 | только `::before` штампа |
| `--fx-scrap-filter` | `url(#rough-scrap)` 0.035 / scale 8.5 | только `::before` клочка |

Правила: фильтры смещения не применяются к тексту и ко всей странице. Фото товаров не растрируются и без текстуры. Клочки: `clip-path: polygon()` на 16–20 точек, у каждого свой массив (`.scrap--a` … `.scrap--f`). Скотч: полоска с зубчатыми торцами, поворот от -25° до 25°.

## 7. Компоненты (разметка + состояния)

Именование BEM. У каждого компонента – пример и состояния.

### 7.1 Штамп `.stamp`
```html
<span class="stamp stamp--red stamp--rect" style="--rot:-7deg">Новая коллекция</span>
<span class="stamp stamp--blue stamp--round" style="--rot:12deg">Одобрено лабораторией</span>
<span class="stamp stamp--red stamp--on-dark">…</span>   <!-- на фото: фон-бумага, обычный режим -->
```
Oswald 700, заглавные, рамка `--border-stamp` на `::before` с фильтром `rough-stamp` (текст не искажается), наклон `--rot` от -9° до 12°, на бумаге `multiply`. Круглый – двойное кольцо (`::after`).
Состояния: скрыт до появления → `.is-stamped` (пришлёпывание 280 мс, один раз); при `prefers-reduced-motion` виден сразу. Не перекрывает цену, название, размеры, кнопки. Не более 4–5 на экран.

### 7.2 Кнопки `.btn`
```html
<a class="btn btn--primary" href="#catalog">Смотреть коллекцию <span aria-hidden="true">→</span></a>
<button class="btn btn--cart" type="button">В корзину</button>
<a class="btn btn--ghost" href="#">О бренде →</a>
```
| | primary | cart | ghost (на тёмном) |
|---|---|---|---|
| Фон / текст | red / white, Oswald 700 17 px | ink / paper-ink, 14 px | прозрачный / paper-ink |
| Рамка, тень | 3 px ink, `--shadow-hard` | нет | 1.5 px paper-ink |
| Высота | ≥ 52 px | 44 px | 52 px |
| Hover | сдвиг 3 px, `--shadow-hard-sm` | фон red-dark | фон paper-ink, текст ink |
| Active | без тени, сдвиг 6 px | – | – |
| Focus-visible | контур 3 px blue, отступ 3 px | то же | контур 3 px paper-ink |
| Disabled | kraft, текст ink-soft, без тени | то же | – |
| Особое | – | после клика «Добавлено» 1.5 с | – |
Наклон у кнопок покупки запрещён.

### 7.3 Ссылка `.link`
```html
<a class="link" href="#">Читать манифест</a>
```
IBM Plex Mono 12 px, заглавные, подчёркивание 2 px ink. Hover: подчёркивание red. Focus: контур blue. Область клика ≥ 44 px по высоте (паддинг).

### 7.4 Ярлык `.tag`
```html
<span class="tag">Готов к диссекции</span>
```
Фон red, белый Oswald 600 12 px (жирное начертание 12 px на красном – 5.16:1), наклон 3°. Варианты текста: «Готов к диссекции», «Последние», «Снято с продаж».

### 7.5 Карточка товара `.card`
```html
<article class="card card--hero">
  <div class="card__meta"><span class="card__label">Образец_01 // 540 GSM</span><span class="tag">…</span></div>
  <div class="card__photo ph"><span class="ph__label">[фото образца 01]</span></div>
  <div class="card__body">
    <h3 class="card__title">Футболка классическая</h3>
    <p class="card__desc">Хлопок 540 GSM, унисекс-крой.</p>
    <p class="card__price">1450 ₽</p>
    <div class="sizes" role="group" aria-label="Размер"> <button class="sizes__btn" aria-pressed="false">S</button> … </div>
    <p class="card__hint" aria-live="polite"></p>
    <button class="btn btn--cart">В корзину</button>
  </div>
</article>
```
Рамка 1.5 px ink, фон paper-3, фото 4:5 без текстуры. Модификаторы: `--hero` (6 колонок, горизонтальная, цена 44 px, характеристики), `--row` (горизонтальная компактная), `--sold` (зачёркнутые размеры).
Состояния: hover – подъём 4 px + `--shadow-hard`; выбранный размер – фон ink; распроданный размер – зачёркнут, `disabled`; без размера при «В корзину» – подсказка red-dark и фокус на группе; после добавления – кнопка «Добавлено». Фильтр скрывает карточку атрибутом `hidden`.

### 7.6 Клочок-архив `.scrap`
```html
<article class="scrap scrap--a" style="--rot:-2.5deg">
  <span class="tape" style="--rot:-14deg" aria-hidden="true"></span>
  <p class="scrap__case">Дело 01 // 2025</p> <h3 class="scrap__title">Альбедо</h3>
  <div class="scrap__photo ph ph--bw">…</div> <span class="stamp stamp--blue">Снято с продаж</span> …
</article>
```
Рваная бумага (`clip-path` + `rough-scrap` на `::before`), ч/б растровая заглушка, синий штамп, номер дела, пометка от руки. Hover и focus-within: выпрямляется до 0°.

### 7.7 Пометка от руки `.note`
```html
<span class="note">если между размерами – бери больший</span>
<svg class="note__arrow" aria-hidden="true"><path pathLength="1" d="…"/></svg>
```
Caveat 600, цвет `--color-accent-text`; обводка и стрелки – SVG `stroke` 2.5 px red. Состояние: прорисовка `stroke-dashoffset` 1 → 0 при появлении (420 мс). Не больше 3 на экран.

### 7.8 Поле ввода `.field`
```html
<div class="field">
  <label class="field__label" for="email">Адрес электронной почты</label>
  <input class="field__input" id="email" type="email" placeholder="name@domain.ru" aria-describedby="email-msg">
  <p class="field__msg" id="email-msg" aria-live="polite"></p>
</div>
```
Фон paper-3, рамка 1.5 px ink, высота 52 px, моно-плейсхолдер. Focus: контур 3 px blue. Error (`.field--error`): рамка red-dark, текст red-dark, тряска 2 × 3 px за 240 мс, `aria-invalid="true"`. Success (`.field--success`): рамка blue, синий штамп «Принято».

### 7.9 Аккордеон `.faq`
```html
<h3 class="faq__q"><button class="faq__btn" aria-expanded="true" aria-controls="faq-1">Как выбрать размер?<span class="faq__mark" aria-hidden="true">–</span></button></h3>
<div class="faq__a" id="faq-1">…</div>
```
Oswald 600, маркер «+», линия 1 px между пунктами. Открыто: «–», панель видима и появляется сдвигом + прозрачностью (`--dur-base`). Высота меняется сразу: анимируются только `transform` и `opacity`. Первый пункт открыт.

### 7.10 Бегущая строка `.ticker`
Фон ink, верхняя линия red 3 px, Oswald 500 15 px, трекинг 0.24em, разделители «★» red (декоративные, `aria-hidden`). Полный круг 36 с. Пауза при hover и focus-within; при reduced-motion строка статична. Дубликат текста скрыт от скринридера.

### 7.11 Навигация `.nav`
Липкая (`position: sticky`), после 80 px скролла получает `.nav--compact` (высота 56 px, логотип уменьшается через `transform`). Снизу двойная линия 3 px. Пункты: hover – красное подчёркивание 2 px; активный (`aria-current`) – чёрное. Кнопка «Корзина · N» – фон ink, счётчик растёт, `aria-live` объявляет добавление.

### 7.12 Заглушка фото `.ph`
```html
<div class="ph" style="--ar:4/5"><span class="ph__label">[фото образца 01]</span></div>
```
Замена одной строкой: `<span class="ph__label">…</span>` → `<img src="…" alt="…">`. `.ph--bw` – ч/б с растром и зерном (только фото бренда).

## 8. Движение

| Токен | Значение |
|---|---|
| `--dur-fast` | 120ms – hover цвета, фокус |
| `--dur-base` | 220ms – подъём карточки, кнопки, аккордеон |
| `--dur-slow` | 420ms – появление блоков, прорисовка пометок |
| `--dur-stamp` | 280ms – пришлёпывание штампа |
| `--dur-shake` | 240ms – тряска поля |
| `--dur-ticker` | 36s – круг бегущей строки |
| `--dur-added` | 1500ms – «Добавлено» (используется в JS) |
| `--ease-out` | cubic-bezier(.2,.8,.2,1) |
| `--stagger` | 120ms – задержка между штампами hero |

- Штамп: `scale(1.35) rotate(var(--rot) - 6deg)`, opacity 0 → `scale(1) rotate(var(--rot))`, opacity .9; 280 мс, без пружины, один раз.
- Блоки при скролле: `translateY(24px)` + opacity, `IntersectionObserver`, один раз. Без JS контент виден.
- Анимируются только `transform` и `opacity`. Никакого parallax и scroll-jacking.
- Ошибка поля: тряска 2 × 3 px за 240 мс. Успех: синий штамп «Принято».
- `@media (prefers-reduced-motion: reduce)`: анимации и переходы выключены, штампы и пометки видны сразу, строка статична.

## 9. Доступность

- Основной текст ≥ 4.5:1, крупный ≥ 3:1 (см. §2.3). Мелкий текст не лежит на текстуре или фото без подложки.
- Видимый фокус везде: `outline: 3px solid var(--color-focus); outline-offset: 3px` (на тёмном – paper-ink).
- Клавиатура: Tab, Enter, Space; аккордеон – `button` с `aria-expanded`; размеры – `aria-pressed`; фильтр – `aria-pressed`.
- Цели клика ≥ 44 px.
- Один `h1` (название газеты), `h2` у каждого блока, `nav`, `main`, `footer`, `lang="ru"`, ссылка «Перейти к содержанию».
- Декор (`.tape`, стрелки, зерно, звёзды, дубль бегущей строки) – `aria-hidden="true"`. Смысловые штампы («Тираж ограничен», «Снято с продаж») читаются как текст или имеют `visually-hidden` эквивалент.
- Сообщения формы и корзины – `aria-live="polite"`; ошибка поля связана через `aria-describedby`, `aria-invalid`.

## 10. Можно и нельзя

**Можно:** наклон декора до 12°; перекрытие клочков; рукописные пометки; неточная привязка на hero-заголовке и шапке; растр на фото бренда.

**Нельзя:**
- наклон у кнопки покупки, цены и размеров; размытые тени у кнопок; третий акцентный цвет;
- штампы поверх цены, названия, размеров, кнопки покупки и поверх фото товара; больше 4–5 штампов на экран;
- текстура и растр на фото товара;
- фиолетовые и бирюзовые градиенты, glassmorphism, закруглённые карточки с мягкими тенями, Inter, эмодзи, шаблонные иконки;
- тексты, логотип, раскладка и люди из референса; Parental Advisory; чужие бренды; цитаты песен;
- выдуманные отзывы, награды, цифры, телефоны, адреса, сроки – только заглушки в квадратных скобках;
- длинное тире «—»; обороты «инновационные решения», «уникальный опыт», «погрузитесь в мир».

## 11. Именование

- Переменные: `--color-*`, `--font-*`, `--text-*`, `--space-*`, `--fx-*`, `--dur-*`, `--ease-*`, `--border-*`, `--shadow-*`; компонентные: `--btn-*`, `--card-*`, `--stamp-*`, `--nav-*`.
- Классы BEM: блок `.card`, элемент `.card__title`, модификатор `.card--sold`. Состояния – `.is-*` (`.is-stamped`, `.is-visible`, `.is-added`).
- JS-хуки – `data-*` атрибуты (`data-filter`, `data-add`, `data-sizes`), без привязки к классам оформления.
- Якоря секций: `#catalog`, `#archive`, `#manifest`, `#protocol`, `#sizes`, `#registry`, `#letters`, `#faq`, `#subscribe`.
